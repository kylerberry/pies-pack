# ADR 005 — Work kind variants

[Raw source](../../raw/adr/005-work-kind-variants.md)

Normalization classifies work as feature, bug, or refactor. Features use criterion-first red/green tests, bugs first reproduce the symptom, and refactors preserve behavior through existing tests. The DAG schema stays at five fields.
