# ADR 011 — Evaluation independence

[Raw source](../../raw/adr/011-evaluation-independence.md)

The lead performs primary evaluation with retained grounding and plan context. Escalated nodes receive a cold, read-only, different-family second opinion that sees only diff, criteria, verify map, and raw evidence, then reruns verification.
