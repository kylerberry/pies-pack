# ADR 013 — Per-node learnings

[Raw source](../../raw/adr/013-per-node-learnings.md)

Nodes write distinct files to the resolved project knowledge sink, avoiding parallel merge conflicts. Grounding reads configured project knowledge sources; after merge, the supervisor verifies placement without a shared-file consolidation or scheduling barrier.
