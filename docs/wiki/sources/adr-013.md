# ADR 013 — Per-node learnings

[Raw source](../../raw/adr/013-per-node-learnings.md)

Nodes write distinct learning files to avoid parallel merge conflicts. Grounding reads learnings from merged predecessors; the supervisor consolidates them once at a wave boundary.
