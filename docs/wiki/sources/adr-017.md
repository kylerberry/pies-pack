# ADR 017 — Cumulative wave brief

[Raw source](../../raw/adr/017-wave-brief.md)

The supervisor updates a cumulative brief after each successful merge; an explicit barrier may still create a review boundary. It leads with product and maintainer behavior, persists outside transient context, and uses contracts before transcripts.
