# ADR 001 — Hands-off operation

[Raw source](../../raw/adr/001-hands-off-operation.md)

PIES optimizes for hands-off operation. Human comprehension comes from node contracts and wave briefs rather than line-by-line diff review. Evaluation quality and readable node output are therefore merge-critical.
