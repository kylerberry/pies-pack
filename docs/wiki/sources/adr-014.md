# ADR 014 — Git-derived node status

[Raw source](../../raw/adr/014-status-from-git.md)

DAG status is derived from `Node: <id>` trailers on first-parent Git history. `scripts/dag-next` computes the ready frontier. Stored status fields and files are rejected as a second source of truth.
