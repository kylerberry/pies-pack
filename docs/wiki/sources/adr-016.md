# ADR 016 — Positive agent bindings

[Raw source](../../raw/adr/016-positive-agent-bindings.md)

PIES names the binding for each stage: scout grounds, worker implements, `pies-simplifier` deletes only, the node lead evaluates, and `pies-evaluator` provides escalation-only second opinion. Named bindings replace broad prohibitions.
