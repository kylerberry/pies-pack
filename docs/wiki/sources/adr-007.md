# ADR 007 — Bar asymmetry

[Raw source](../../raw/adr/007-bar-asymmetry.md)

Criteria and verification configuration may be added or tightened without ceremony. Weakening or removing either requires a recorded amendment with supporting evidence. Amendments lead the node contract.
