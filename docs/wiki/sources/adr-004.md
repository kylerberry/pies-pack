# ADR 004 — Input normalization and criteria provenance

[Raw source](../../raw/adr/004-input-normalization.md)

Every run normalizes to `id`, `intent`, `change_spec`, and `acceptance_criteria`. DAG criteria pass through with `dag` provenance; standalone criteria are authored and marked `authored`. A standalone task that contains two mergeable outcomes stops for decomposition.
