# ADR 008 — Real-surface verification

[Raw source](../../raw/adr/008-real-surface-verification.md)

`pies.config.yaml` maps checks, real surfaces, and feature proofs. Nodes run applicable checks and prove changed behavior on the correct surface. Inconclusive or wrong-surface proof is not a pass; map additions are additive.
