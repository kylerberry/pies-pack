# ADR 002 — Lead plans and evaluates; worker implements

[Raw source](../../raw/adr/002-lead-plans-worker-implements.md)

The lead owns planning, review, and the pass/fail decision. The worker alone writes production code. This separation protects evaluation from implementation context and keeps lead context focused on intent and evidence.
