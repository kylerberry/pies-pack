# ADR 021 — Plan-first public interface and lifecycle

[Raw source](../../raw/adr/021-plan-first-public-interface.md)

PIES exposes plans rather than DAG mechanics: `/pies-create-plan` saves an immutable spec-backed plan; `/pies-run-plan` explicitly approves and delivers it. The internal DAG, rolling admission, five-field schema, and Git-derived status remain. Progressive capability proof remains the planning standard, while failed planning attacks become persistent warnings rather than creation blockers. Fanout remains parallel assistance, not plan delivery.
