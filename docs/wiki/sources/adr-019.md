# ADR 019 — DAG admission policy

[Raw source](../../raw/adr/019-dag-admission-policy.md)

DAG dependencies remain durable, while admission is replaceable. Rolling-frontier admission is default; the caller selects active-node concurrency at runtime, and `--barriered` preserves deliberate batch boundaries. Non-passing nodes freeze only transitive dependents, and shared-exclusive verification remains serialized.
