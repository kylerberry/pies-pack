# ADR 009 — Multiple verified commits per node

[Raw source](../../raw/adr/009-multiple-commits-per-node.md)

A node may contain multiple focused commits, each verified before the next. The supervisor preserves them through a `--no-ff` merge so node history remains reviewable and bisectable.
