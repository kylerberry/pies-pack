# ADR 020 — Task-kind routing

[Raw source](../../raw/adr/020-task-kind-routing.md)

Routing registry `kind-profiles.json` is runtime truth across seven kinds; router input is pre-run `intent` + `change_spec` only. Shadow mode is default; authoritative mode auto-routes only calibrated implementation kinds above `0.85`. Documentation, research, and codebase-analysis stay lead-selected; report-only kinds are standalone, contract-terminated, and rejected by DAG admission.
