# ADR 003 — Lead realization by context

[Raw source](../../raw/adr/003-lead-realization-by-context.md)

A node lead keeps grounding, plan, review, and evaluation context. Children receive file pointers rather than copied transcripts, return bounded artifacts, and are replaced rather than steered when direction changes. The current execution skill makes session hosting prompt-owned rather than architecture-owned.
