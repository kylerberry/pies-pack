# ADR 003 — Node lead as a context role

[Raw source](../../raw/adr/003-lead-realization-by-context.md)

A node lead keeps grounding, plan, review, and evaluation context. Direct runs use the initiating session; DAG prompts establish one isolated lead in the assigned worktree. PIES specifies artifacts and terminal evidence, while the invoking prompt selects hosting.
