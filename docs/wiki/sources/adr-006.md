# ADR 006 — Grounding and design aids

[Raw source](../../raw/adr/006-grounding-and-design-aids.md)

Every run scouts affected code and prior learnings. Standalone runs also recall context. Prototypes settle local behavioral forks; boundary-crossing work gets a types-and-signatures sketch. Trivial grounding skips require a recorded reason.
