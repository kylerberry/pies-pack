# 2026-09-23 — Added project knowledge discovery and run records

PIES no longer assumes `docs/learnings/`. Scout resolves project knowledge sources and an optional learning sink from `pies.config.yaml` and project instructions; absent a sink, it writes no project learning. The lead now owns a compact `run-record.json` per terminal outcome, while the DAG supervisor retains terminal and merge facts separately.

The [[../../planning/roadmap|roadmap]] records Graphify as the preferred future query layer for the self-improvement evidence corpus. No Graphify integration was implemented.
