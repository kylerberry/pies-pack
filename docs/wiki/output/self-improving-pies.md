# Self-improving PIES

[Proposal](../../self-improving-pies.md)

PIES policy should change through versioned variants, fixed benchmarks, paired real-task trials, and human-gated promotion. Lead-owned compact run records, DAG terminal outcomes, and wave briefs form the future evidence corpus; raw `~/.pies` checkpoints and transcripts remain linked evidence, not the default analysis corpus. Graphify is the proposed future query layer. Hard invariants for proof, safety, and failure visibility outrank cost improvements.
